# AI Prompt Refinement

A premium English editorial site about AI prompt refinement and AI video generation, built for Vercel.

## Local Development

```bash
npm install
npm run dev
```

## Deploy

Upload the full project to a GitHub repository, import it in Vercel, and deploy.

## Edit Articles

Article content lives in `lib/articles.ts`. Add a new article by copying one item and changing its title, excerpt, category, slug, and content.
